Claim Track V1
========================
Theme fullscreen Claim Track V1 untuk ClaimTrack Core.

Kompatibel dengan WordPress Pages terpisah untuk Dashboard, Fase Klaim, FASE 1, FASE 2, FASE 3, input, master data, import/export, pengaturan, dan E-Knowledge.
WP Admin Bar tetap disembunyikan pada frontend ClaimTrack.

Version 1.12.0: kompatibilitas layout dashboard untuk halaman FASE 1/2/3 di area konten kanan.

ClaimTrack Theme v1.12.1: sinkronisasi shell dashboard untuk halaman fase.

ClaimTrack Theme v1.13.0: penyelarasan visual fase dengan tema ClaimTrack dan responsivitas desktop/tablet/mobile.

ClaimTrack Theme v1.14.0: sinkronisasi cache/theme untuk layout FASE 1 KDP full-width.
